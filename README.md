## Запуск

У папці `code` (замінити останню цифру на потрібне завдання):

```sh
g++ -std=c++17 lab_5_1.cpp -o lab
./lab
g++ -std=c++17 test_5_1.cpp -o test
./test
```

У Windows виконувані файли можна назвати `lab.exe`, `test.exe`.
Кожен `test_5_*.cpp` вже підключає потрібну реалізацію; окремо додавати
відповідний `lab_5_*.cpp` у той самий тестовий проєкт не потрібно.

Або з установленим CMake, з папки `code`:

```sh
cmake -S . -B build
cmake --build build --config Debug
ctest --test-dir build -C Debug --output-on-failure
```

Приклади введення:

| Завдання | Вхід |
|---|---|
| 5.1 | `1 2` |
| 5.2 | `-1 1 0.5 0.00001` |
| 5.3 | `-1 1 4` |
| 5.4.1–5.4.4 | `5` |
| 5.5 | `13 16` |

Перевірено clang++: 32 unit-тести та 22 інтеграційні перевірки пройдено.
CMake-конфігурацію додано для зручності; у цьому середовищі збірку виконано
безпосередньо clang++.
