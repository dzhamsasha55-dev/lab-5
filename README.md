Кожен звіт містить: умову, математичну модель, структурну схему,
структуровані таблиці функцій і змінних, блок-схеми за ГОСТ 19.701-90
(стрілки лише на лініях повернення циклів), UML-діаграми діяльності
(стрілки на всіх переходах), текст програми з коментарями, unit-тести,
таблицю результатів тестів і фактичний вивід програми.

Програми виводять результати у вигляді таблиць з рамками.

## Запуск

У папці `code` (замінити останню цифру на потрібне завдання):

```sh
g++ -std=c++17 lab_5_1.cpp -o lab
./lab
g++ -std=c++17 test_5_1.cpp -o test
./test
```

Або з CMake, з папки `code`:

```sh
cmake -S . -B build
cmake --build build --config Debug
ctest --test-dir build -C Debug --output-on-failure
```

| 5.2 | `-1 1 0.5 0.00001` |
